# Finite JSON tail replay

This is a distinct, separately gated launcher for exactly the 92 original occurrences left `not_run` by the staged first run. `tail-ids.jsonl` is the ordered identity/source list. `generation.json`, `generated_base.py.txt`, `setup.py.txt`, and `positive_launcher.py` bind the existing generator, six leaf modules in package order, and the exact ID-slice selection. Upstream tests and original fixtures were unchanged.

The imported first-party bad-store gate on this actual launcher is in `architecture-control/`. It required a fresh O0 build with the exact matching runtime and no cache to exit nonzero with `expected int, got bool` and no image. `build.json` binds the pin, compiler/runtime hashes, distinct launcher hash, commands, and fresh O0/O3 image hashes.

All windows inherit the original 8 MiB soft/unlimited hard stack and original process limits. Fresh stock uses the exact finite window and pinned CPython. Each tool original has its own eight-second window; the encoding recursion original has its own 25-second window. The other windows cover disjoint non-tool ranges. `{stock,O0,O3}.capture.json` records exact argv, environment, limit, exit, ID/occurrence, raw event line, and trace controls per window. Raw stderr/stdout are concatenated with window headers; original strace streams are concatenated and gzip-compressed without modification other than those headers.

For native windows, all 19 original staged JSON test sources and the finite launcher were absent, and no test bytecode existed. Fixtures remained. `withdrawal.json` records the preimage/restoration hashes. The native-only `deny_python.c` interposer targets CPython executable names and libpython loads, allows other child programs, and is independently audited by exec/open traces and readelf/ldd. It is not a security sandbox. Real Imre CLI/clang child behavior remains observable. Tool originals receive no pair credit even on a triple pass, because their CLI subprocess behavior cannot satisfy the no-child-exec/control requirement. The first-run decoding timeout and repeated doctest identities remain unchanged. The unlimited-stack/nproc=0 experiment is separately labeled auxiliary evidence under `../tail-window-1`; no stock or native outcomes are borrowed from it.
