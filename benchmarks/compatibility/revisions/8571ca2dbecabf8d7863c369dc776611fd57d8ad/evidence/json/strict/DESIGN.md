# Partial JSON activation design

The existing staged `stdlib/json.jsonl` has 216 original occurrences. Its IDs, occurrences and historical raw outcomes must be preserved. Four staged doctest source fields disagree with the frozen canonical registration source, so byte-identical staging and unconditional canonical source anchoring cannot both hold; that discrepancy is documented in `doctest-source-attribution.json`. The final staged shard corrects only those four source fields to the immutable frozen registration source, retaining the separate docstring source provenance and every ID, occurrence, invocation and raw outcome. It includes 34 tool timeouts, two recursion timeouts, raw failures/errors/skips, and inactive `paired` flags that have no authority. A `finite` raw-control cohort requires a matching completed stock/native inventory; `stock-only` requires the absent native originals to be `not_run`. Neither contract can encode real timeout/window observations without lying about them. The existing inactive-family staged model preserves them, but cannot activate a strict subset.

The partial-family activation puts only fully controlled JSON receipts in a distinct `verified/stdlib/json.jsonl` shard, digest-binds both that verified shard and the staged shard with its four documented source corrections, and requires exact source/platform/revision/ID/occurrence membership in the staged originals. Only the verified shard enters the validated-receipt and pair totals. Every staged ID and occurrence must be anchored to the frozen canonical inventory or immutable pinned inventory. Staged observations are counted separately and explicitly labeled unverified, with their outcomes not checked by the renderer; staged claims and flags could never activate them. The staged shard and original captures retain the historical timeout observations. The existing raw-control finite validator requires every selected cohort's exact stock/native inventory, positive/negative graph, matched build identities, withdrawal evidence, and raw results.

This activation rests on merged generic source-byte fix `3b6fd616`. Digest-rebound source, launcher/cohort, staged-to-finite/paired, native-revision, invented or source-tampered staged ID, forged staged outcome, and malformed-capture negatives must pass. `raw_control.py` is unchanged by the JSON work.
