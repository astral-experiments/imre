# Finite-unittest raw control binding

`raw-control-v1` is a shared snapshot adapter for finite unittest launchers. A family's `raw-control/binding.json` maps each exact `(id, occurrence)` to a named `launcher_cohort` and gives each cohort its own raw artifacts; it does not assert control verdicts. Every receipt must have exactly one mapping. Raw outcomes and all controls are checked only for the selected cohort; a family-level gate cannot credit another launcher. Additional cohorts use the same validator with separate positive launchers, negative gates, images and withdrawal traces. Its activation entry binds the receipt, the binding, and every artifact by SHA-256. The snapshot's explicit `activation.json` entries bind csv and base64 independently. Do not infer activation from a receipt's `paired` field.

The adapter independently anchors each source/ID/occurrence to the canonical inventory; checks raw stock collection, ordered starts/results and full receipt coverage; joins native results by the same key and exact raw line; and leaves stock-only originals as `not_run` without an omission. It validates the clean pinned source, build output and artifact hashes, stock interpreter/version/platform and both stock and native test-source hashes, the positive launcher and saved image identities, matched no-cache O0/O3 commands, and the poisoned launcher as precisely one imported first-party module whose contents are `status: int = True`. The raw gate trace must show the compiler opening both files, exiting nonzero with the int/bool diagnostic, and no output image before or after. No witness or credit boolean establishes these conditions.

For each saved image, the supervisor trace must show the whole staged `Lib/test` tree (including matching `.pyc` files) renamed away and the exact source absent before and after native execution, then restored. The restored source hash must match. Raw withdrawn outcomes must equal baseline outcomes byte for byte. The trace covers descendant exec attempts, all `open`, `openat`, `openat2`, `creat`, and `io_uring_setup` calls; an extra exec attempt, source/bytecode or CPython/libpython open, successful io_uring setup, missing wait status, or linked libpython rejects credit. `openat2` matters: the pinned compiler uses it for the negative launcher and poison. A native test that legitimately needs a child still cannot receive credit through this adapter. In base64 the five `TestMain` originals remain collected by stock and raw `not_run` on both native tiers, with no accepted omission.

The trace and its digests are evidence to review, not a cryptographic attestation of the machine that produced it. Explicit, reviewed activation is the authority boundary. The adapter rejects semantic tampering even after witness, metadata, binding, and activation digests are recomputed; it cannot authenticate wholesale fabricated logs.

Focused Cloud controls used the existing saved images and exact 8571ca2 CLI/runtime; no suite was rebuilt or delegated to CPython. `collect_raw_controls.py` captures the control commands; `probe-build.raw` shows the small C supervisor's reproducible hash. To validate the real merged receipts and a rehashed tampered raw-open witness and an unverified launcher mapping using the real manifest entries:

```sh
python -m unittest discover -s benchmarks/compatibility -p test_raw_control.py -v
```

Validated results: csv 128 raw rows, stock 124 pass/4 skip, O0 and O3 122 pass/6 skip, 122 validated pairs; base64 41 raw rows, stock 41 pass, O0 and O3 35 pass/1 skip/5 not_run, 35 validated pairs. These values require the explicit digest-bound activation entries. The canonical 49f cohort is unchanged.
