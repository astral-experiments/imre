# Archive dispatch

On the Linux devbox, all 28 original `TestArchives` occurrences were accounted for at both O0 and O3. One complete method and its assertions ran in Imre under the original host fixture. Sixteen methods called native operations from their original CPython bodies, ten used both runtimes, and one retained CPython's zstd skip. The [per-method archive report](archive-linux.json) includes public call counts, callback roles, filesystem errors and the skip reason.

The four registration and working-directory methods made 16 native calls per optimization level. In each, a single Imre process held the packing registry across registration, listing, dispatch and removal. The original closures and assertions ran in CPython. The fixture forwarded only actual native `chdir` events to the original hook: two calls for the legacy packer and none for the default or root-aware packer. Their arguments, cwd and the three registration errors matched the pinned CPython oracle. Integer tuple rows under registration are carried as native lists, so the registration-only method is also classified as mixed.

The [paired controls](https://github.com/astral-sh/imre/actions/runs/40194394062) also checked mutable `supports_root_dir` across two registrations of the same native function, callback exception propagation, dry runs, archive interoperability, ten crossed exception handlers, 40 root-path cases and five removed-working-directory cases. The compiler/runtime source was tree `aa9cdee42fa02f88f14dcebbdbe06f972bdeb660` (archive `e90ade9`, random `24a0e84`); only the verification workflow differed in the hosted checkout. All four unchanged whole-suite entries reached the next private export, `shutil._GiveupOnFastCopy` at line 18, with zero tests executed.

To reproduce the class observations, run the pinned CPython 3.14.5 binary with [archive_ops.py](archive_ops.py), passing `--imre`, `--runtime`, `--clang` and `--result`. [archive_pack_controls.py](archive_pack_controls.py) takes the same toolchain arguments and compares native stdout with CPython in real temporary directories.
